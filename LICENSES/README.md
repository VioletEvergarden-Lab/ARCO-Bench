# Distribution terms and sources

| Material | Terms or source |
|---|---|
| ARCO-Bench code, constructed tasks and reference plans | The repository has no selected project-wide license. This distribution introduces no new license grant. |
| ADDS-derived task data | Michał Kłodawski, ADDS dataset v1.0, [doi:10.5281/zenodo.20491777](https://doi.org/10.5281/zenodo.20491777), CC0 1.0. The task geometry and demand derive from this public logistics simulation dataset; UAV schedules, disruptions and resource semantics are benchmark adaptations. |
